# 01. 시작하기

Claude Code를 처음 접하거나, 환경을 새로 셋업할 때 보는 카테고리.

## 이럴 때 본다
- 처음 설치/로그인부터 첫 작업까지 빠르게 가고 싶다
- 어느 환경(CLI/IDE/Desktop/Web)에서 시작할지 결정해야 한다
- Claude Code가 내부적으로 어떻게 동작하는지 (에이전틱 루프) 알고 싶다
