# Ultraplan을 더 이상 사용할 수 없습니다

> 제거된 Ultraplan 연구 미리보기를 로컬 계획을 위한 계획 모드 또는 클라우드 세션을 위한 웹의 Claude Code로 대체합니다.

Anthropic이 Ultraplan 연구 미리보기를 제거했습니다. 연구 미리보기는 실험적이며 피드백에 따라 변경되거나 제거될 수 있습니다. 제거 범위는 다음을 포함합니다:

* `/ultraplan` 명령어
* `ultraplan` 키워드 트리거
* 계획 승인 대화상자의 **아니요, Claude Code 웹에서 Ultraplan으로 개선하기** 옵션

계획 워크플로우의 경우 다음을 사용하세요:

* [계획 모드](/docs/ko/permission-modes#analyze-before-you-edit-with-plan-mode): 로컬 세션에서 Claude가 코드베이스를 조사하고 변경을 수행하기 전에 승인을 위해 계획을 제시합니다
* [웹의 Claude Code](/docs/ko/claude-code-on-the-web): 클라우드에서 Claude Code 세션을 실행하고 브라우저에서 변경 사항을 검토합니다
