자동 모드
연구 미리보기

자동 모드는 권한 프롬프트를 분류기에 넘깁니다. 안전한 편집과 명령은 중단 없이 실행되고, 파괴적이거나 의심스러운 작업은 차단되어 표시됩니다. 모든 파일 쓰기를 승인하는 것과 `--dangerously-skip-permissions`로 실행하는 것 사이의 중간 지점입니다.

![Claude Code 프롬프트 푸터에 노란색으로 표시된 '자동 모드 켜짐(Shift+Tab으로 순환)' 표시기](https://mintcdn.com/claude-code/CfffsX01JHFnIKvD/images/whats-new/auto-mode.png?fit=max\&auto=format\&n=CfffsX01JHFnIKvD\&q=85\&s=367c9e9d4ba5bc57ec4b935154bf1fbb)

Shift+Tab으로 자동 모드로 순환하거나 기본값으로 설정합니다:

```json ~/.claude/settings.json {3} theme={null}
{
  "permissions": {
    "defaultMode": "auto"
  }
}
```

[권한 모드 가이드](https://code.claude.com/docs/ko/permission-modes.md)

트랜스크립트 검색
v2.1.83

트랜스크립트 모드에서 `/`를 눌러 대화를 검색합니다. `n`과 `N`은 일치 항목을 단계별로 진행합니다. 마침내 Claude가 400개 메시지 전에 실행한 그 Bash 명령을 찾을 수 있는 방법입니다.

트랜스크립트 모드를 열고 검색합니다:

```text Claude Code theme={null}
Ctrl+O    # open transcript
/migrate  # search for "migrate"
n         # next match
N         # previous match
```

[전체 화면 가이드](https://code.claude.com/docs/ko/fullscreen.md#search-and-review-the-conversation)

PowerShell 도구
미리보기
v2.1.84

Windows는 Bash와 함께 기본 PowerShell 도구를 얻습니다. Claude는 cmdlet을 실행하고, 객체를 파이프하고, Git Bash를 통해 모든 것을 변환하지 않고 Windows 기본 경로로 작업할 수 있습니다.

설정에서 옵트인합니다:

```json .claude/settings.json {3} theme={null}
{
  "env": {
    "CLAUDE_CODE_USE_POWERSHELL_TOOL": "1"
  }
}
```

[PowerShell 도구 문서](https://code.claude.com/docs/ko/tools-reference.md#powershell-tool)

조건부 hooks
v2.1.85

Hooks는 이제 권한 규칙 구문을 사용하여 `if` 필드를 선언할 수 있습니다. 사전 커밋 검사는 모든 bash 호출 대신 `Bash(git commit *)`에 대해서만 생성되어 바쁜 세션에서 프로세스 오버헤드를 줄입니다.

git 커밋만으로 hook의 범위를 지정합니다:

```json .claude/settings.json {5} theme={null}
{
  "hooks": {
    "PreToolUse": [{
      "hooks": [{
        "if": "Bash(git commit *)",
        "type": "command",
        "command": ".claude/hooks/lint-staged.sh"
      }]
    }]
  }
}
```

[Hooks 참조](https://code.claude.com/docs/ko/hooks.md)
