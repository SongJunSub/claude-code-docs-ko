CLI의 컴퓨터 사용
research preview

지난주 컴퓨터 사용이 Desktop 앱에 출시되었습니다. 이번주는 CLI에 출시됩니다: Claude는 네이티브 앱을 열고, UI를 클릭하고, 자신의 변경사항을 테스트하고, 문제를 수정할 수 있으며, 모두 터미널에서 가능합니다. 웹 앱은 이미 검증 루프를 가지고 있었습니다. 네이티브 iOS, macOS 및 기타 GUI 전용 앱은 그렇지 않았습니다. 이제 가능합니다. 호출할 API가 없는 앱과 도구의 루프를 닫는 데 가장 좋습니다. 아직 초기 단계입니다. 거친 부분이 있을 수 있습니다.

깜빡임 없는 렌더링
v2.1.89

가상화된 스크롤백이 있는 새로운 alt-screen 렌더러를 선택하십시오. 프롬프트 입력은 하단에 고정되고, 마우스 선택은 긴 대화에서 작동하며, 다시 그릴 때의 깜빡임이 없습니다. `CLAUDE_CODE_NO_FLICKER`를 설정 해제하여 롤백하십시오.

<video autoPlay muted loop playsInline src="https://mintcdn.com/claude-code/CfffsX01JHFnIKvD/images/whats-new/flicker-free.mp4?fit=max&auto=format&n=CfffsX01JHFnIKvD&q=85&s=7719e35e52a3f9734b0cf69edac333ad" />

환경 변수를 설정하고 Claude Code를 다시 시작하십시오:

```bash theme={null}
export CLAUDE_CODE_NO_FLICKER=1
claude
```

[전체 화면 렌더링](https://code.claude.com/docs/ko/fullscreen.md)

MCP 결과 크기 오버라이드
v2.1.91

MCP 서버 작성자는 이제 도구의 `tools/list` 항목에서 `anthropic/maxResultSizeChars`를 설정하여 특정 도구의 자르기 상한을 높일 수 있으며, 최대 500K 문자까지 가능합니다. 상한은 전역이었으므로 데이터베이스 스키마 또는 전체 파일 트리와 같이 본질적으로 큰 페이로드를 반환하는 도구는 기본 제한에 도달하고 파일 참조와 함께 디스크에 저장되었습니다. 도구별 오버라이드는 도구가 정말로 필요할 때 해당 결과를 인라인으로 유지합니다.

서버의 `tools/list` 응답에서 도구에 주석을 달아주십시오:

```json highlight={5} theme={null}
{
  "name": "get_schema",
  "description": "Returns the full database schema",
  "_meta": {
    "anthropic/maxResultSizeChars": 500000
  }
}
```

[MCP 참조](https://code.claude.com/docs/ko/mcp.md#raise-the-limit-for-a-specific-tool)

PATH의 플러그인 실행 파일
v2.1.91

플러그인 루트의 `bin/` 디렉토리에 실행 파일을 배치하면 Claude Code는 플러그인이 활성화된 동안 해당 디렉토리를 Bash 도구의 `PATH`에 추가합니다. Claude는 절대 경로나 래퍼 스크립트 없이 모든 Bash 도구 호출에서 바이너리를 명령어로 호출할 수 있습니다. CLI 헬퍼를 호출하는 명령어, 에이전트 및 훅 옆에 패키징하는 데 편리합니다.

플러그인 루트에 `bin/` 디렉토리를 추가하십시오:

```text highlight={4, 5} theme={null}
my-plugin/
├── .claude-plugin/
│   └── plugin.json
└── bin/
    └── my-tool
```

[플러그인 참조](https://code.claude.com/docs/ko/plugins/manifest-reference.md#standard-layout)
