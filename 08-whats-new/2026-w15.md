# 15주차 · 2026년 4월 6–10일

> Ultraplan 클라우드 계획, 자동 페이싱 /loop이 있는 Monitor 도구, 설정을 패키징하기 위한 /team-onboarding, 그리고 터미널에서 /autofix-pr을 사용합니다.

4가지 기능 · 4월 6–10일

Ultraplan
연구 미리보기

터미널에서 클라우드의 계획 모드를 시작한 다음 브라우저에서 결과를 검토합니다. Claude는 웹 세션의 Claude Code에서 계획을 작성하는 동안 터미널은 자유로워집니다. 준비가 되면 개별 섹션에 대해 의견을 달고, 수정을 요청하고, 원격으로 실행하거나 CLI로 다시 보낼 수 있습니다. v2.1.101부터 첫 번째 실행은 기본 클라우드 환경을 자동으로 생성하므로 시도하기 전에 웹 설정 단계가 없습니다.

<video autoPlay muted loop playsInline src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/ultraplan.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=e8f2f23730c6a5c289dbf3e7b13eadf6" />

명령을 실행하거나 모든 프롬프트에 키워드를 포함하기만 하면 됩니다:

```text title="Claude Code" wrap theme={null}
/ultraplan migrate the auth service from sessions to JWTs
```

[Ultraplan 가이드](https://code.claude.com/docs/ko/ultraplan)

Monitor 도구
v2.1.98

백그라운드 감시자를 생성하고 해당 이벤트를 대화로 스트리밍하는 새로운 기본 제공 도구입니다. 각 이벤트는 새로운 트랜스크립트 메시지로 도착하며 Claude는 즉시 반응합니다. 학습 실행을 추적하거나, PR의 CI를 감시하거나, 개발 서버 충돌이 발생하는 순간 자동으로 수정할 수 있으며, 모두 Bash sleep 루프가 턴을 열어두지 않고도 가능합니다.

<video autoPlay muted loop playsInline src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/monitor-tool.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=f4156c15a0999de5c5157f54a3117c89" />

Claude에게 작업을 계속하는 동안 무언가를 감시하도록 요청합니다:

```text title="Claude Code" wrap theme={null}
Tail server.log in the background and tell me the moment a 5xx shows up
```

이는 `/loop`과 함께 작동하며, 이제 자동 페이싱됩니다. 간격을 생략하면 Claude는 작업에 따라 다음 틱을 예약하거나, Monitor 도구를 사용하여 폴링을 완전히 건너뜁니다.

```text title="Claude Code" wrap theme={null}
/loop check CI on my PR
```

[Monitor 도구 참조](https://code.claude.com/docs/ko/tools-reference.md#monitor-tool)

/autofix-pr
CLI

PR 자동 수정은 13주차에 웹에 도착했습니다. 이제 터미널을 떠나지 않고 켤 수 있습니다. `/autofix-pr`은 현재 브랜치의 열린 PR을 추론하고 한 단계로 웹의 Claude Code에서 자동 수정을 활성화합니다. 브랜치를 푸시하고, 명령을 실행하고, 떠나세요. Claude는 CI와 검토 의견을 감시하고 초록색이 될 때까지 수정을 푸시합니다.

<video autoPlay muted loop playsInline src="https://mintcdn.com/claude-code/aFXPQxiBOW99MHS3/images/whats-new/autofix-pr.mp4?fit=max&auto=format&n=aFXPQxiBOW99MHS3&q=85&s=95f191eb4711130a128aec3f6b720527" />

PR의 브랜치에서 실행합니다:

```text title="Claude Code" wrap theme={null}
/autofix-pr
```

[풀 요청 자동 수정](https://code.claude.com/docs/ko/claude-code-on-the-web.md#auto-fix-pull-requests)

/team-onboarding
v2.1.101

로컬 Claude Code 사용에서 팀원 온보딩 가이드를 생성합니다. 잘 알고 있는 프로젝트에서 실행하고 출력을 새로운 팀원에게 전달하여 기본값에서 시작하는 대신 설정을 재생할 수 있습니다.

실제로 시간을 보낸 프로젝트에서 실행합니다:

```text title="Claude Code" wrap theme={null}
/team-onboarding
```

[명령 참조](https://code.claude.com/docs/ko/commands.md)

기타 개선 사항

포커스 보기: 깜박임 없는 모드에서 `Ctrl+O`를 눌러 보기를 마지막 프롬프트, 한 줄 도구 요약(diffstats 포함) 및 Claude의 최종 응답으로 축소합니다로그인 화면의 가이드 [Amazon Bedrock](https://code.claude.com/docs/ko/amazon-bedrock.md) 및 [Google Cloud의 Agent Platform](https://code.claude.com/docs/ko/google-vertex-ai.md) 설정 마법사: 단계별 인증, 지역, 자격 증명 확인 및 모델 고정을 위해 "3rd-party platform"을 선택합니다`/agents`는 탭 레이아웃을 가집니다. Running 탭은 `● N running` 카운트가 있는 라이브 서브에이전트를 표시하고, Library 탭에서 Run agent 및 View running instance 작업을 수행합니다기본 노력 수준은 이제 API 키, Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry, Team 및 Enterprise 사용자의 경우 `high`입니다(`/effort`로 제어)`/cost`는 구독 사용자를 위한 모델별 및 캐시 히트 분석을 표시합니다`/release-notes`는 이제 대화형 버전 선택기입니다상태 줄: 새로운 `refreshInterval` 설정은 N초마다 명령을 다시 실행하고, JSON 입력에서 `workspace.git_worktree`를 사용합니다`CLAUDE_CODE_PERFORCE_MODE`: Edit/Write는 자동으로 덮어쓰는 대신 `p4 edit` 힌트와 함께 읽기 전용 파일에서 실패합니다OS CA 인증서 저장소는 이제 기본적으로 신뢰되므로 엔터프라이즈 TLS 프록시는 추가 설정 없이 작동합니다(`CLAUDE_CODE_CERT_STORE=bundled`로 옵트아웃)Mantle에서 제공하는 Amazon Bedrock: `CLAUDE_CODE_USE_MANTLE=1`을 설정합니다강화된 Bash 도구 권한: 백슬래시 이스케이프 플래그, 환경 변수 접두사, `/dev/tcp` 리다이렉트 및 복합 명령은 이제 올바르게 프롬프트합니다`UserPromptSubmit` 훅은 `hookSpecificOutput.sessionTitle`을 통해 세션 제목을 설정할 수 있습니다
