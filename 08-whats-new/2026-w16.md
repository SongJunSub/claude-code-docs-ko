# 16주차 · 2026년 4월 13–17일

Claude Opus 4.7
새로운 모델

Anthropic의 가장 강력한 코딩 모델이 이제 Max 및 Team Premium의 기본값이며, `/model`에서 다른 모든 곳에서도 사용할 수 있습니다. `high`와 `max` 사이에 위치하는 새로운 `xhigh` 노력 수준을 추가합니다. 대부분의 코딩 및 에이전트 작업에 최적의 결과를 제공하며, 4.7로 처음 전환할 때 기본값으로 적용됩니다. `/effort`는 이제 인수 없이 호출할 때 대화형 화살표 키 슬라이더를 열어서 수준 이름을 기억하지 않고도 지능과 속도를 조절할 수 있습니다.

모델과 노력 수준을 한 번에 전환하기:

```text Claude Code theme={null}
> /model opus
> /effort xhigh
```

[모델 설정: 노력 수준](https://code.claude.com/docs/ko/model-config.md#adjust-effort-level)

루틴
웹

일정에 따라, GitHub 이벤트에 따라, 또는 API 호출에 따라 실행되는 템플릿 클라우드 에이전트입니다. Claude Code 웹에서 프롬프트, 접근할 수 있는 저장소, 필요한 커넥터를 사용하여 루틴을 한 번 정의한 후, PR 열림, 릴리스 게시 또는 자신의 웹훅이 머신을 실행하지 않고도 이를 트리거하도록 합니다. 트리거 선택기는 이제 선택적 필터가 있는 GitHub 이벤트를 포함하며 모든 루틴에 외부 시스템을 위한 토큰화된 `/fire` 엔드포인트를 제공합니다.

/usage 분석

네이티브 바이너리
v2.1.113

`claude` CLI는 이제 번들된 JavaScript 대신 플랫폼별 네이티브 바이너리를 생성하므로, 설치된 `claude` 명령은 더 이상 Node를 호출하지 않습니다. npm 패키지는 `@anthropic-ai/claude-code-darwin-arm64`와 같은 선택적 종속성을 통해 올바른 바이너리를 가져오므로, 설치 명령은 변경되지 않습니다. 독립 실행형 설치 프로그램은 이미 이 바이너리를 제공했으며, npm은 이제 이와 일치합니다.

업그레이드하고 실행 중인 항목 확인하기:

```bash theme={null}
claude update
claude --version
```

[설정 가이드](https://code.claude.com/docs/ko/setup.md)

기타 개선 사항

새로운 [`/ultrareview`](https://code.claude.com/docs/ko/ultrareview): 병렬 다중 에이전트 분석과 적대적 비판 패스를 사용하는 클라우드의 포괄적인 코드 리뷰입니다. 현재 브랜치를 리뷰하려면 그대로 실행하거나, 특정 PR의 경우 `/ultrareview <PR#>`를 실행하세요[자동 모드](https://code.claude.com/docs/ko/permission-modes.md#eliminate-prompts-with-auto-mode)는 이제 Opus 4.7의 Max 구독자에게 제공되며, `--enable-auto-mode` 플래그는 더 이상 필요하지 않습니다[세션 요약](https://code.claude.com/docs/ko/interactive-mode.md#session-recap)은 자리를 비운 동안 발생한 일의 한 줄 요약을 표시합니다. `/recap`을 요청 시 실행하거나 `/config`에서 끕니다새로운 `/tui` 명령과 `tui` 설정은 대화 중에 클래식과 깜박임 없는 렌더링 사이를 전환합니다. 포커스 보기는 `Ctrl+O`에서 자신의 `/focus` 명령으로 이동했습니다플러그인은 세션 시작 또는 스킬 호출 시 자동으로 활성화되는 최상위 `monitors` 매니페스트 키를 통해 백그라운드 감시자를 제공할 수 있습니다`/theme`의 "자동 (터미널과 일치)" 옵션은 터미널의 어두운/밝은 모드를 따릅니다`/fewer-permission-prompts`는 트랜스크립트에서 일반적인 읽기 전용 Bash 및 MCP 호출을 스캔하고 `.claude/settings.json`에 대한 허용 목록을 제안합니다Claude는 이제 스킬 도구를 통해 `/init`, `/review`, `/security-review`와 같은 기본 제공 명령을 발견하고 실행할 수 있습니다`PreCompact` 훅은 코드 2로 종료하거나 `{"decision":"block"}`를 반환하여 압축을 차단할 수 있습니다`ENABLE_PROMPT_CACHING_1H`는 API 키, Amazon Bedrock, Google Cloud의 Agent Platform, Microsoft Foundry 사용자를 1시간 프롬프트 캐시 TTL로 옵트인합니다`sandbox.network.deniedDomains` 설정은 더 광범위한 `allowedDomains` 와일드카드에서 특정 도메인을 제외합니다`/undo`는 이제 `/rewind`의 별칭이며, `/proactive`는 `/loop`의 별칭입니다강화된 Bash 권한: 거부 규칙은 이제 `env`/`sudo`/`watch` 래퍼를 통해 일치하며, `Bash(find:*)` 허용 규칙은 더 이상 `-exec` 또는 `-delete`를 자동으로 승인하지 않습니다
