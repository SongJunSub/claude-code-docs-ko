/ultrareview
research preview

이제 공개 연구 미리보기로 제공됩니다. Ultrareview는 클라우드에서 버그 헌팅 에이전트 플릿을 실행하여 브랜치 또는 PR에 대해 검토하고, 발견 사항이 CLI 또는 Desktop으로 자동으로 전달됩니다. 인증 또는 데이터 마이그레이션과 같은 중요한 변경 사항을 병합하기 전에 실행하세요.

<video autoPlay muted loop playsInline src="https://mintcdn.com/claude-code/FTi4SBJ9YRs7d-5X/images/whats-new/ultrareview.mp4?fit=max&auto=format&n=FTi4SBJ9YRs7d-5X&q=85&s=0fb1271365d38f414ad155aeb8edb08e" />

현재 브랜치를 검토합니다:

```text Claude Code theme={null}
> /ultrareview
```

또는 PR을 지정합니다:

```text Claude Code theme={null}
> /ultrareview 1234
```

[Ultrareview 가이드](https://code.claude.com/docs/ko/ultrareview.md)

세션 요약
CLI

세션에서 포커스를 전환했다가 돌아오면 자신이 없는 동안 일어난 일에 대한 한 줄 요약을 받습니다. 여러 Claude 세션을 동시에 실행하면서 흐름을 유지하는 데 도움이 됩니다.

<video autoPlay muted loop playsInline src="https://mintcdn.com/claude-code/FTi4SBJ9YRs7d-5X/images/whats-new/session-recap.mp4?fit=max&auto=format&n=FTi4SBJ9YRs7d-5X&q=85&s=0a8db1470bd0161a47efeb2f322af76f" />

`/config`에서 요청 시 요약을 생성하거나 자동 요약을 끕니다:

```text Claude Code theme={null}
> /recap
```

[대화형 모드: 세션 요약](https://code.claude.com/docs/ko/interactive-mode.md#session-recap)

커스텀 테마
v2.1.118

`/theme`에서 명명된 색상 테마를 빌드하고 전환하거나, `~/.claude/themes/`의 JSON 파일을 직접 편집합니다. 각 테마는 기본 프리셋을 선택하고 관심 있는 토큰만 재정의합니다. 플러그인도 테마를 배포할 수 있습니다.

테마 선택기를 열고 새로운 테마를 만듭니다:

```text Claude Code theme={null}
> /theme
```

[터미널 설정: 커스텀 테마 만들기](https://code.claude.com/docs/ko/terminal-config.md#create-a-custom-theme)

웹용 Claude Code
web

기타 개선 사항

[Vim 비주얼 모드](https://code.claude.com/docs/ko/interactive-mode.md#vim-editor-mode): 프롬프트 입력에서 문자 선택을 위해 `v`를 누르거나 줄 선택을 위해 `V`를 누르고, 연산자 및 시각적 피드백을 사용합니다Hooks는 이제 [`type: "mcp_tool"`](https://code.claude.com/docs/ko/hooks#mcp-tool-hook-fields)을 통해 MCP 도구를 직접 호출할 수 있으므로, hook이 프로세스를 생성하지 않고 이미 연결된 서버에 접근할 수 있습니다`/cost`와 `/stats`는 [`/usage`](https://code.claude.com/docs/ko/commands)로 병합되었습니다. 이전 이름은 여전히 관련 탭을 여는 입력 단축키로 작동합니다`/config` 변경 사항(테마, 편집기 모드, 상세 정보 등)은 이제 `~/.claude/settings.json`에 유지되며 다른 [설정](https://code.claude.com/docs/ko/settings.md)과 동일한 프로젝트/로컬/정책 우선순위를 따릅니다[포크된 서브에이전트](https://code.claude.com/docs/ko/sub-agents.md#fork-the-current-conversation)는 `CLAUDE_CODE_FORK_SUBAGENT=1`로 외부 빌드에서 활성화할 수 있습니다: 포크는 처음부터 시작하는 대신 전체 대화 컨텍스트를 상속합니다Pro 및 Max 구독자의 Opus 4.6 및 Sonnet 4.6에 대한 기본 [노력 수준](https://code.claude.com/docs/ko/model-config.md#adjust-effort-level)은 이제 `high`입니다(이전: `medium`)네이티브 macOS 및 Linux 빌드는 `Glob` 및 `Grep` 도구를 Bash를 통해 사용 가능한 내장 `bfs` 및 `ugrep`으로 대체하여 별도의 도구 라운드 트립 없이 더 빠른 검색을 제공합니다`--from-pr`은 이제 github.com 외에도 GitLab 병합 요청, Bitbucket 풀 요청, GitHub Enterprise PR URL을 허용합니다자동 모드: [`autoMode.allow`, `soft_deny`, 또는 `environment`](https://code.claude.com/docs/ko/auto-mode-config)에 `"$defaults"`를 포함하여 기본 제공 목록을 대체하는 대신 커스텀 규칙을 추가합니다새로운 [`claude plugin tag`](https://code.claude.com/docs/ko/plugins/dependencies#tag-plugin-releases-for-version-resolution) 명령은 버전 검증을 통해 플러그인에 대한 릴리스 git 태그를 만듭니다Opus 4.7 세션은 이제 모델의 네이티브 1M 컨텍스트 윈도우에 대해 계산되어 부풀려진 `/context` 백분율과 조기 자동 압축을 수정합니다`/resume`은 대규모 세션에서 최대 67% 더 빠르며 이제 다시 읽기 전에 오래되고 큰 세션을 요약할 것을 제안합니다
