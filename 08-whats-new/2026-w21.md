Pro 플랜의 자동 모드
CLI

자동 모드는 이제 Pro 플랜에서 사용 가능하며 Opus와 함께 Sonnet 4.6을 지원합니다. 권한 프롬프트를 백그라운드 안전 검사로 대체합니다. 일상적인 작업은 중단 없이 실행되고, 파괴적이거나 의심스러운 작업은 차단되고 표시됩니다.

Claude Code를 업데이트한 후 Shift+Tab으로 모드를 전환합니다. 계정이 요구 사항을 충족하면 자동 모드가 나타납니다:

```bash terminal theme={null}
claude update
```

명령은 새 버전 번호와 함께 `Successfully updated`를 출력하거나, 업데이트가 필요하지 않으면 `Claude Code is up to date`를 출력합니다. 자동 모드가 활성화되면 프롬프트 바닥글에 `auto mode on`이 표시됩니다.

[자동 모드 요구 사항](https://code.claude.com/docs/ko/permission-modes.md#eliminate-prompts-with-auto-mode)

기타 개선 사항

[`/usage`](https://code.claude.com/docs/ko/costs#track-your-costs)는 이제 플랜 한도를 주도하는 요소를 카테고리별로 분류하여 표시하며, 최근 사용량을 스킬, 서브에이전트, 플러그인 및 개별 MCP 서버에 귀속시킵니다"Extra usage"는 CLI 전체에서 "usage credits"로 이름이 변경되었으며, `/extra-usage`는 이제 `/usage-credits`입니다. 이전 이름도 계속 작동합니다. 이 명령은 `/login`을 통해 claude.ai 구독으로 로그인해야 하며 API 키 인증에서는 사용할 수 없습니다.새로운 [`/code-review`](https://code.claude.com/docs/ko/code-review) 명령은 `/code-review high`와 같은 선택한 노력 수준에서 정확성 버그를 보고하며, `--comment`는 결과를 인라인 GitHub PR 댓글로 게시합니다. `/simplify`는 별도의 정리 전용 검토로 유지됩니다.백그라운드 세션은 이제 `/resume`에 대화형 세션과 함께 나타나며 `bg`로 표시되고, `claude agents`에서 `Ctrl+T`로 고정된 세션은 유휴 상태일 때도 유지됩니다`claude agents --json`은 상태 표시줄 및 세션 선택기와 같은 스크립팅을 위해 라이브 세션을 JSON으로 나열합니다PowerShell 도구는 이제 Amazon Bedrock, Google Cloud의 Agent Platform 및 Microsoft Foundry 사용자를 위해 Windows에서 기본적으로 활성화되며, `CLAUDE_CODE_USE_POWERSHELL_TOOL=0`으로 옵트아웃할 수 있습니다`claude plugin disable`은 이제 다른 활성화된 플러그인이 대상에 의존할 때 거부하며, `claude plugin enable`은 전이적 종속성을 강제로 활성화합니다`/plugin` 마켓플레이스 찾아보기 창은 예상 컨텍스트 비용을 표시하며, Discover 및 Browse 화면은 설치 전에 플러그인의 명령, 에이전트, 스킬, 훅 및 MCP/LSP 서버를 나열합니다새로운 `worktree.bgIsolation: "none"` 설정을 사용하면 백그라운드 세션이 `EnterWorktree` 없이 작업 복사본을 직접 편집할 수 있으며, worktree가 비실용적인 저장소의 경우입니다Markdown 출력은 GFM 작업 목록 체크박스를 렌더링하며, `/diff` 상세 보기는 키보드로 스크롤합니다상태 라인 JSON 입력은 이제 감지될 때 GitHub 저장소 및 PR 정보를 포함합니다엔터프라이즈: `allowAllClaudeAiMcps` 관리 설정은 `managed-mcp.json`과 함께 claude.ai 클라우드 MCP 커넥터를 로드합니다
