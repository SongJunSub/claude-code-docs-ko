# 08. What's New / 릴리스 노트

Claude Code의 변경 이력. 주별 다이제스트는 대부분 한국어, 전체 릴리스 노트(`changelog`)는 영문 원문.

## 이럴 때 본다
- 최근 며칠 사이 추가된 기능이 뭔지 빠르게 파악
- 특정 버전 이후 변경점을 추적해야 할 때
- 어떤 기능이 새로 들어왔다는 얘기를 들었는데 정확한 사용법이 알고 싶을 때
